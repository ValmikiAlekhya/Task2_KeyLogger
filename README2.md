# Task 2: Python Keylogger Project

## Description

This is a simple Python-based keylogger developed for educational purposes only. It captures and logs keyboard input and saves the output into a text file.

**Note:** This project is intended strictly for learning and should never be used unethically or without permission.

---

## Features

- Records keystrokes in real time
- Saves log data to a `.txt` file
- Can run in the background

---

## How to Run

1. Make sure Python is installed on your system.
2. Save the script as `keylogger.py`.
3. Run the script using:

```bash
python keylogger.py
4. A log file (e.g., key_log.txt) will be created with captured keystrokes
Requirements
python 3.x
pynput library

Install pynput by running:
pip install pynput
